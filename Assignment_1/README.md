Assignment 01: Menu-Driven Arithmetic Calculator
📌 Description
A modular Java application that performs basic arithmetic operations.
This project focuses on clean code structure, method decomposition, and robust user input validation to prevent runtime errors (such as division by zero).
✨ Features
🧭 Menu-Driven Interface
Implements a switch-case structure for an interactive user experience.
🔢 Input Validation
Uses Scanner validation to ensure only numeric values are accepted.
🧩 Modular Design
Each arithmetic operation is implemented in a separate static method:
Addition
Subtraction
Multiplication
Division
⚠️ Error Handling
Explicitly checks for division by zero to maintain program stability.
🔄 Program Logic Flow
Display a menu with available arithmetic operations.
User selects an operation.
User enters two numeric values.
Inputs are validated.
The corresponding method is called.
Result is displayed.
User chooses to perform another calculation or exit.
